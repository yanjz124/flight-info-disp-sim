Delta Gate Display Control

Flight this is everything the screen shows

Leave Actual empty and the screen reads DEPARTS. Fill it in and it becomes WAS / NOW while the flight is still here, then SCHEDULED / ACTUAL once it has gone — which is how the real screens switch.

Status

At Gate → Boarding (35 min out) → Boarding Ended (10 min out) → Departed.

Bottom ribbon

Find a flight FlightView covers Delta, so this works the same as on the United page

  1. Drag this button to your bookmarks bar (one time): Send to gate display
  2. Look one up below, or open an airport's departures on FlightView and click the bookmark there.

Display

The screen carries no gate number, no boarding zone and no upgrade or standby list — the real ones don't either. Boarding groups appear on a separate screen, which this doesn't build yet.
