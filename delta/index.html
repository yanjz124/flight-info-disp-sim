Delta · Gate Display Control

Flight this is everything the screen shows

Leave Actual empty and the screen reads DEPARTS. Fill it in and it becomes WAS / NOW while boarding is under way, or SCHEDULED / ACTUAL once the status is itself about time — Delayed, Early, Boarding Ended. That is how the real screens switch.
